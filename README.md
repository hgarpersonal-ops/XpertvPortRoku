# XuperTV para Roku

Port no oficial de **XuperTV** adaptado y optimizado para dispositivos **Roku** (Roku OS). Este proyecto permite ejecutar la interfaz y funcionalidades de XuperTV directamente en televisores y reproductores Roku mediante instalación manual (Sideloading / Modo Desarrollador).

## Características principales
* Interfaz adaptada a la navegación con control remoto Roku.
* Soporte para resoluciones HD y Full HD.
* Optimizado para un rendimiento fluido en dispositivos Roku compatibles.

## ✅ Dispositivos probados y testeados
Esta versión ha sido probada y verificada con éxito en los siguientes modelos:
* **Roku TV 32" (TCL)**
* **Roku Express 4K**
* **Roku 2**

> **¿Lo probaste en otro modelo?** Si instalaste y testeaste este port en un dispositivo Roku diferente y quieres que lo agregue a la lista de compatibilidad, **escríbeme al privado** con el modelo exacto y tu experiencia.
